# JAX Renderer 0.5.0

## Highlights

- **Custom shader contract updated.** Fragment processing now returns typed `Fragment` targets and alpha. Mixing receives the fragment batch and a `destination` pixel state, and decides target and depth writes independently. `FragmentCollection.NEAREST` remains the default; `ALL` retains candidates for custom multi-layer mixing. See the [shader contract and migration guide](../shader-contract.md) before upgrading custom shaders. The high-level `Renderer` canvas tuple API is unchanged. Alpha blending is not implemented.
- **More consistent rendering behaviour.** Double-sided objects can make back-facing geometry visible in the main and shadow passes, without changing `gl_FrontFacing` or flipping normals. Empty scenes return the configured background. Resetting an object's orientation restores the identity orientation.
- **Numerical and geometry fixes.** Normal transformation now handles local scaling with range-aware inverse scaling and per-row normalisation, with documented behaviour and limits for zero-scale inputs. Shadow camera construction is more stable when its up direction is nearly parallel to its view direction. Texture data ownership is preserved when meshes use independent UV indices. Camera-gradient coverage now compares selected physical-parameter gradients with finite differences; this is a regression check, not a guarantee for every scene or camera parameter.
- **Stronger typing and CI.** The package now ships `py.typed`, the renderer code and public shader pipeline have stricter typed contracts, and CI configuration adds accelerator checks and periodic TPU result collection alongside lint, type and render checks.

## Upgrade notes

Custom shaders must migrate to the new fragment and mixing contract described in the [migration guide](../shader-contract.md). In addition, generic typing aliases previously re-exported from `renderer` and the `renderer.replace_dict` helper have been removed; import typing constructs from `typing` or `collections.abc`, and use dictionary union (`base | updates`) when merging dictionaries.

The supported requirements remain Python 3.12–3.14, NumPy 2.1.3 or newer, and JAX/JAXLib 0.11.2 or newer. The locked development environment uses JAX 0.12.0; this is the tested lock version, not a raised minimum requirement.
